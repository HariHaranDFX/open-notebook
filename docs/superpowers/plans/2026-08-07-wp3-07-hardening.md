# WP3-07 Hardening and Release Verification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the complete WP3 redesign preserves product behavior, permissions, branding, accessibility, responsiveness, localization, performance, and build integrity, then reconcile the implemented design system back into the single DESIGN.md.

**Architecture:** This package adds no product features. It runs cross-route audits, closes only verified gaps, executes the full automated and browser matrix, and updates documentation from the final code.

**Tech Stack:** Vitest, Testing Library, ESLint, Next.js build, pytest, project license checker, browser accessibility/visual inspection.

## Global Constraints

- No release claim without fresh full-suite/build evidence.
- Do not suppress test, lint, type, accessibility, or localization failures.
- Fix root causes in shared components when multiple routes exhibit the same issue.
- Do not refactor unrelated backend/frontend code during hardening.
- The final repository retains one root DESIGN.md and no prototypes or design sidecar.
- The final DESIGN.md reflects implemented tokens/components, removes the seed marker, and remains in canonical eight-section order.

### Task 1: Run static design-contract audits

**Files:**
- Modify only files that fail a verified audit.

**Interfaces:**
- Consumes the complete WP3 implementation.
- Produces a zero-result anti-pattern audit or documented intentional exceptions inside components.

- [ ] **Step 1: Scan for visual regressions**

Run:

```powershell
rg -n "text-\[(?:9|10|11)px\]|rounded-(?:xl|2xl|3xl)|shadow-(?:md|lg|xl|2xl)|group-hover:opacity-100|hover:scale|translateY|bg-gradient|backdrop-blur" frontend/src
```

Expected: no routine app-surface hits. Inspect every result; keep only semantically justified pill/overlay/press behavior and encode that justification in the component test or nearby comment.

- [ ] **Step 2: Scan for untranslated user text**

Run:

```powershell
rg -n ">[A-Z][^<{]{2,}<|aria-label=\"|placeholder=\"|title=\"" frontend/src --glob "*.tsx"
```

Expected: only non-user identifiers, test fixtures, or translated expressions. Replace real UI literals with locale keys in all locales.

- [ ] **Step 3: Scan for unsafe errors and hover-only controls**

Search for API URLs, stack/trace text, raw error rendering, `opacity-0`, and click handlers on non-semantic containers. Replace only confirmed user-facing or inaccessible cases.

### Task 4: Execute the responsive and accessibility matrix

**Files:** None unless a verified scenario fails.

- [ ] **Step 1: Inspect four widths in both themes**

Use 375×812, 768×1024, 1024×768, and 1440×900. Visit login, notebooks, notebook workbench, sources, source workbench, Ask, Search, podcasts, episode detail, transformations, general settings, API keys, groups, advanced, and sharing.

For each, verify no horizontal viewport scrolling, correct drawer/rail/sidebar state, readable 35–60ch mobile and 60–75ch desktop prose, independent workbench pane scrolling, sticky elements reserving space, and dark/light contrast parity.

- [ ] **Step 2: Keyboard-only pass**

Verify skip link, navigation, create menu, library rows/actions, context selectors, pane resizers, chat/Ask cancel, references, dialogs/sheets, forms, tabs, destructive confirmations, focus return, and route-change focus.

- [ ] **Step 3: Accessibility preferences**

Verify 200% zoom, largest practical browser text scaling, reduced motion, RTL locale, CJK locale, screen-reader names/roles/states, polite async announcements, error alerts, and at least 44×44px coarse-pointer targets.

- [ ] **Step 4: Resilience pass**

Verify offline, slow response, timeout, 401 restore, 403 read-only, 404 return, 429 retained request, API unavailable, language loading, long titles, large lists, long chats, empty collections, concurrent change notice, and no unsafe error disclosure.
